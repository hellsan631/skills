# Attribution

Twenty-five of the skills here started as someone else's work. Both sources are MIT
licensed, which permits the copy and asks that the original notice travel with it. This
file is that notice.

These copies are not vendored dependencies. They are ours to edit, and most have already
diverged. `imports.json` records the commit each one was taken at so
`python3 scripts/imports.py diff` can show what the original authors changed since, which
keeps their later improvements readable without letting them overwrite our work.
