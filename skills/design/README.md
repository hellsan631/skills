# Design skills

Use these skills for game design documents, player interfaces, and visual identity.

| Skill | Use when |
| --- | --- |
| [principal-game-designer](principal-game-designer/SKILL.md) | Writing, revising, reviewing, or auditing game design documents |
| [game-ui-design](game-ui-design/SKILL.md) | Designing game screens, visual direction, composition, and interaction states |
| [game-visual-identity](game-visual-identity/SKILL.md) | Aligning design pillars, exploring art direction, and producing consistent characters, icons, and related assets |
| [midjourney-prompting](midjourney-prompting/SKILL.md) | Preparing Midjourney prompts and model setup, guiding manual generation, and refining returned images |
| [visual-identity-grilling](visual-identity-grilling/SKILL.md) | Iterating on game art through short decision rounds, rendered comparisons, and targeted revisions |
