# Practitioner design references

Read these practitioners' accounts for the reasons behind their design choices. Inspect the linked images when using a case as a visual reference. The applications below are this skill's synthesis; each game's solution belongs to its own activity and art direction.

## Beastieball: a consistent visual language

Greg Lobanov describes using skewed parallelograms, repeated moving patterns, and a shared palette to give Beastieball's dense RPG interface its sporting character. He connects interface choices to where the player places attention and how they experience the game. [Read the designer's article](https://www.gamedeveloper.com/art/deep-dive-developing-a-clear-and-consistent-visual-language-in-the-ui-of-beastieball).

Apply the lesson by choosing a small set of shapes, typographic relationships, color roles, and motion treatments that express the game. Carry them through dense lists and supporting controls as well as large panels. The useful transfer is a repeatable visual language; a parallelogram is appropriate only when it serves the new direction.

## VALORANT: compose around the game moment

Riot's 2022 interface preview describes a lobby organized around player cards and action through contrast, value changes, and simpler shapes. Agent key art expresses character personality. Mirrored team banners support rivalry in the faceoff screen, while the MVP composition expresses the result. [Read the team's redesign notes](https://playvalorant.com/en-us/news/game-updates/preview-the-future-of-valorant-s-interface/).

Apply the lesson by choosing the subject and feeling before distributing panels. Use scale, artwork crop, value, and the relationship between regions to express preparation, rivalry, ownership, or accomplishment. This is a documented design intention, not evidence that every change improved usability.

## League of Legends: visual importance follows gameplay importance

Riot's clarity article connects visual prominence to the gameplay impact of an effect and discusses the need to control overall noise. It also explains how recognizable silhouettes and established visual meanings survive changes in appearance. The article concerns champions and effects. [Read Clarity in League](https://www.leagueoflegends.com/en-us/news/dev/clarity-in-league/).

The HUD application is an inference: give immediate danger and useful responses appropriate visual priority, preserve recognizable state cues, and keep decorative intensity from obscuring the playable scene. Menu compositions can use different emphasis because players have different time and attention available there.
